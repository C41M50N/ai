# AI SDK Client

AI SDK Client is a wrapper of Vercel's AI SDK that provides a more convenient interface for making LLM calls. It includes features like request cost tracking, a model registry, and lazy provider loading.

The goal is to provide a more ergonomic and **type-safe** way to make LLM calls and manage multiple AI providers and models in a single application, without having to manually handle provider instances or track costs on every call.
